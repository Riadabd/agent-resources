# Description

The goal of this repo is to automatically generate an AGENTS.md file based on input criteria you provide:
- Language(s)
- Version control
- Coding & testing methodologies
- Behavior
- Degree of feedback

# Layout

The idea would be to have the following layout:
- Quick summary on important points
- Mindset
  - Explains how you want the agent to approach things
  - Provides a blueprint on how to act in certain situations
- Tooling
- Testing
- Language
   - This section will house best practices for each language.
   - Will be based on what I have found and will find online from trustworthy engineers who have tuned the language agent specs to maximize their efficiency.
- Communication preferences
- Environment and setup
  - Can house particular instructions on what has to be done in the environment before any command has to be run (e.g. `nix`, ...)
